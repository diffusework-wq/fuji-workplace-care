# 肌推｜台中企業推拿與拔罐

[開啟網站](https://diffusework-wq.github.io/fuji-workplace-care/)

提供肩頸舒緩、背部放鬆、手臂舒展與拔罐的品牌網站提案。

此專案為純靜態 HTML、CSS 與 JavaScript，透過 GitHub Pages 發布。更新 main 分支後會重新部署。

合作需求單僅在瀏覽器內產生，可複製或下載；沒有實際預約、寄送、付款或資料庫功能。影像為 AI 情境示意，非真實團隊或客戶實績。正式費用、聯絡方式及營運資訊待補。

## 本機預覽

在專案目錄執行 `python -m http.server 4173`，開啟 http://localhost:4173/。
